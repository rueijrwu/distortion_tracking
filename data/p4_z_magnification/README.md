# P4 Z magnification study

Run `Script\analyze_p4_z_magnification.py` with the project Python environment to collect or analyze the isolated P4 z1 magnification sweep. The script saves the structured records, metadata, fit pickle, report, and PNG here. The default dataset has 5 accommodations, 5 RC rotations, 51 absolute Cornea_ENT_D THI values, and 9 field points per state (11,475 rows).
